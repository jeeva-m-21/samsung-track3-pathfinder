Read: PLAN.md (Section 8.4, 11.3, 12.1), docs/SPEC.md, src/ref/mathlib.py
Allowlist: src/cpp/mat.h, src/cpp/quat.h, src/cpp/Makefile, tests/cpp/test_math.cpp
Forbidden: touching anything else; dynamic memory allocation; <iostream>; external libraries (Eigen, etc.)
Steps:
1. Implement `src/cpp/mat.h`:
   - Template `struct Mat<size_t R, size_t C>` storing `double data[R * C]` (or 2D `data[R][C]`) in row-major order.
   - Zero-allocation constructors, `zeros()`, `identity()`, `operator()`, `operator[]`.
   - Matrix addition, subtraction, scalar multiplication/division.
   - Matrix-matrix multiplication `operator*`.
   - Matrix-vector multiplication.
   - Transpose `transpose()`.
   - Type aliases: `Vec3 = Mat<3, 1>`, `Mat3 = Mat<3, 3>`, `Vec15 = Mat<15, 1>`, `Mat15 = Mat<15, 15>`, `Mat3x15 = Mat<3, 15>`, etc.
   - Symmetric / small matrix inversion (e.g. 3x3 inverse for Kalman innovation covariance `(H P H^T + R)^-1`).
2. Implement `src/cpp/quat.h`:
   - Struct `Quat` with `w, x, y, z` (Hamilton convention).
   - Multiplication `operator*` (Hamilton product).
   - `normalize()` with division-by-zero protection (`floor 1e-12`).
   - `conjugate()`, `inverse()`.
   - `to_rot_mat()` returning `Mat3`.
   - `from_rot_mat(const Mat3& R)` using Shepperd's 4-branch method.
   - `rotate(const Vec3& v)` and `rotate_inv(const Vec3& v)`.
   - `skew(const Vec3& v)` returning 3x3 skew-symmetric matrix.
   - `exp_map(const Vec3& phi)` and `log_map(const Quat& q)` with Taylor expansions for small angles (< 1e-8).
   - `ensure_continuity(Quat& q, const Quat& q_prev)` preserving sign.
3. Implement `tests/cpp/test_math.cpp`:
   - Unit tests covering matrix operations, multiplication, transposition, 3x3 inversion.
   - Quaternion operations: Hamilton product, normalization, exp/log maps, rotation matrix conversions, vector rotation, and sign continuity.
   - Includes assertion checks matching Python `mathlib.py` golden outputs.
   - Zero `<iostream>`: use `<cstdio>` (`printf`, `assert`).
4. Update `src/cpp/Makefile` to add `test` target compiling and running `build/test_math`.
5. Run `make -C src/cpp test` and ensure all tests pass.
Tests first: `tests/cpp/test_math.cpp`
Acceptance: `make -C src/cpp test` exits 0 with all math tests passing.
