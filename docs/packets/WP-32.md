     - Inverts 3x3 S analytically.
     - Checks Chi-squared gate y^T S^{-1} y <= gate_threshold.
     - Computes Kalman gain K = P H^T S^{-1}.
     - Computes delta_x = K y.
     - Computes Joseph update P = (I - K H) P (I - K H)^T + K R K^T.
     - Injects error state into nominal state (q = norm(q * exp(delta_theta)), v += delta_v, p += delta_p, b_g += delta_bg, b_a += delta_ba).
     - Resets covariance P = G P G^T where G is identity except G[0:3, 0:3] = I - skew(delta_theta / 2).
     - Conditions covariance.
